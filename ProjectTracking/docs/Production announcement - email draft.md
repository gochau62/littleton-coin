# Email draft — Project Tracking going to production

**Subject:** Project Tracking — what's changing

Hi all,

Project Tracking is being replaced with a rebuilt set of screens. Everything
works the way it does today — same data, same files, same authority. What
changes is the look, plus a few additions noted below.

Your old bookmarks and shortcuts keep working; they land on the new screens
automatically.

Same four tabs — General, IT Stuff, Payback, Steering Committee — and every

assigned* on the IT Stuff tab you can add other programmers, each with their
own work status and scheduled start, and remove one with the trash can.
